Live-fork suites have a separate explicit workflow, fork-tests.yml. They are
not claimed as automatic PR coverage or as passing tests in this repair report.

  Workflow prerequisite: ETHEREUM_SEPOLIA_FORK_RPC_URL secret.
  Writes occur only on a private Anvil fork on loopback, chain 31337, port8546.

Perps commands: npm run test:perps-integration; npm run test:perps-fork
  Required mode: PERPS_FORK_REQUIRED=1
  Workflow prerequisites: ARBITRUM_SEPOLIA_FORK_RPC_URL secret, a verified
  deployed schema-four release, explicit existing account/open position,
  and exact positive close size. Calls are read-only remote eth_call/RPC.
  Prepared deployment or missing prerequisites hard-fail requested runs.

Optional local fork runs explicitly skip unavailable suites. A skip is not
successful deployed-interface coverage. The current prepared perps manifest
cannot supply a live deployed fork control; this work does not remove that guard.

Implementation failures are ordinary required red tests, listed individually
in report.txt. There are no expected-failure markers or CI bypasses for them.
