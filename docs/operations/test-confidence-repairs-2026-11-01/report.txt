Implementation defects fixed
1. Economic event decoders require their exact ABI widths and reject incomplete or oversized data; valid values are preserved.
2. Standalone schema initialization includes dependency-ordered preparation/recovery/diagnostic DDL. History triggers install after source initialization and self-repair partial installations.
3. AA catalog verification binds actual objects to the current schema and expected fingerprints to this connection's temporary objects; foreign/concurrent objects cannot interfere.
4. LP supersession verifies exact canonical receipt and competitor block identities before and after the unchanged no-progress replay. Missing, orphaned or changing evidence retains manual review.
5. The LP Terraform guard uses the canonical release binding. Prepared-release safety and the unsupported legacy-Pimlico compatibility guard remain intact.

Testability changes preserve production defaults. The largest source move places the existing candle CLI in Plether.Perps.CandleAdmin, with the original manifest guard and a private validated-profile integration driver.
Additional harness corrections cover stale UI assumptions, provider/state isolation, and historical fixtures. The integration wrapper now compiles the real manifest instead of replacing deployment data.
